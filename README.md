## Organización de las prácticas
El repositorio está estructurado en carpetas individuales para cada práctica (ej. `practica_1/`). Cada directorio de práctica contiene:
- El cuaderno de Jupyter principal (`.ipynb`) con la documentación y resultados.
- Una carpeta `imagenes/` con las capturas probatorias y diagramas.
- Una carpeta `scripts/` con los códigos fuente desarrollados (Bash, Python, etc.).
